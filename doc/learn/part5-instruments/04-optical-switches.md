# 光开关与光路由

光开关实现光路的选择性切换与重构，是光网络与光学测试系统的关键器件

## 光开关的基本概念

**光开关 (Optical Switch)** 用于在不同光纤/光路间切换、选择或路由光信号， 是光分插复用 (ROADM)、光交叉连接 (OXC)、系统保护倒换与自动测试 (ATE) 的核心器件。

### 与电开关的本质区别

电开关通断的是电流，光开关通断的是**光路**。 由于光子不带电荷、无法像电子一样"切断"，光开关须通过物理移动、折射率调制、 光学非线性等机制改变光的传播路径。

### 主要功能

- **1×N 切换**：1 路输入选切到 N 路输出（或反向 N×1）
- **M×N 矩阵**：N 路输入到 M 路输出的任意连接
- **旁路/保护倒换**：主备路由切换，倒换时间 <50 ms
- **光路重构**：动态调整波长路由（ROADM）

### 关键指标

- **插入损耗 (IL)**：导通态的功率损耗，0.5-3 dB
- **串扰**：非导通端口的泄漏，要求 < -40 dB
- **开关时间**：从触发到稳定的时间，ns-s 不等
- **回波损耗**：反射回输入端的光，要求 >50 dB
- **重复性**：多次切换损耗一致性，<0.05 dB
- **耐功率**：承受最大光功率而不损坏
- **开关次数寿命**：机械类有寿命限制（百万到千万次）

## 机械式光开关

**机械式光开关**通过物理移动光纤或反射镜改变光路，是最成熟、 性能最稳定的方案。

### 类型

- **移动光纤式**：电磁驱动光纤对准不同输出端口，简单可靠
- **移动反射镜式**：反射镜翻转/平移将光反射到不同端口
- **棱镜式**：移动棱镜切换光路

### 特性

- **优点**：插入损耗低（0.5-1 dB）、串扰极好（< -60 dB）、耐功率高、对波长不敏感
- **缺点**：开关时间慢（5-30 ms）、有机械磨损、体积大、不易集成

### 应用

- 光通道保护倒换（主备切换）
- 实验室手动光路切换
- 大功率光路选择

## MEMS 光开关

**MEMS (Micro-Electro-Mechanical Systems)** 是机械开关的微型化版本， 在硅基底上集成数百到数千微镜阵列，是现代大容量光开关的主流方案。

### 工作原理

- **2D MEMS**：微镜在"开/关"两态间翻转，构成 M×N 矩阵，镜面数 = M×N
- **3D MEMS**：微镜双轴倾斜连续调整，两片镜阵构成任意光路，镜面数 = M+N

### 特性

- **优点**：开关速度中等（μs-ms）、可大规模矩阵（如 320×320）、IC 工艺批量制造
- **缺点**：装配精度要求高、受振动/温度影响、寿命相对短（百万元到千万元）

### 应用

- 大型 OXC（核心骨干网交叉连接）
- 自动光测试系统（多通道切换）
- 数据中心光交换

## 波导型光开关

**波导型光开关**在平面光波导 (PLC) 上集成，通过改变波导折射率切换光路， 是集成化、低功耗、高速化的方向。

### 热光开关 (Thermo-Optic)

通过加热器改变波导温度从而改变折射率：

- 基于 MZ 干涉仪或 Y 分支结构
- 调节一臂相位实现 2×2 切换
- 折射率变化：$\Delta n = \frac{dn}{dT} \cdot \Delta T$

| 特性 | 数值 |
| --- | --- |
| 开关时间 | 1-10 ms（受热扩散限制） |
| 插入损耗 | 1-3 dB |
| 串扰 | < -30 dB |
| 功耗 | 数十到数百 mW/单元 |

### 电光开关 (Electro-Optic)

利用 **Pockels 效应**（详见 Part 3 第 03 章）改变波导折射率：

- LiNbO₃ 或 InP 材料平台
- 响应极快：ns 级，适合高速保护倒换与包交换
- 插入损耗 2-4 dB，驱动电压 3-5 V
- 串扰 < -25 dB

### 磁光开关

利用法拉第旋光效应，磁场控制偏振面旋转实现切换：

- 响应 μs 级
- 插损低、串扰好，但成本高、批量难

## 开关矩阵与光路由

### 矩阵拓扑

- **Crossbar**：N×N 全连接，端口数小但灵活，Clos 多级扩展
- **Banyan/Benes**：多级网络，端口多、有阻塞或无阻塞设计
- **Switch-and-Select**：每对输入输出独占一路开关，无阻塞、串扰好但规模受限

### ROADM 中的波长选择开关 (WSS)

**波长选择开关 (WSS)** 是 ROADM 的核心：1 路输入的多个 WDM 波长可独立选择路由到不同输出端口。

- 基于 MEMS + 衍射光栅，或硅基液晶 (LCoS)
- 频谱粒度：50 GHz / 75 GHz / 100 GHz
- 串扰 < -40 dB，插损 3-6 dB
- 支持 "COLORLESS"（无色）方向无关调度

### 光路重构指标

- **倒换时间**：保护倒换 <50 ms，路由重构可达秒级
- **波长阻塞率**：色散/非线性等造成的不可用比例
- **频谱利用率**：弹性光网络 (EON) 按需分配频谱

## 应用场景

### 光通信系统

- **保护倒换**：主路由故障时切换到备用路由
- **OXC**：骨干网任意端口间交叉连接
- **ROADM/WSS**：波长级动态路由
- **光通道监控**：切换到测试口做在线监测

### 自动测试系统

- 多器件并行测试：开关矩阵切换到不同待测件
- 系统自校准：切换到参考通道
- 故障隔离：环回测试

## 总结

光开关是光网络从"静态连接"走向"动态重构"的关键：

- **机械式**：性能稳定、串扰好、速度慢，适合保护倒换
- **MEMS**：规模大、成本可控，是 OXC 的主流方案
- **波导式**：易集成、低功耗，热光偏慢、电光最快
- **WSS**：ROADM 核心，实现波长级动态路由
- 选型须综合权衡开关时间、矩阵规模、插损、串扰、寿命与成本
