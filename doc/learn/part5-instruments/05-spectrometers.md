# 光谱仪与波长计

光谱分析是表征光源、滤波器、波分复用系统的核心测量手段

## 光谱分析的基本概念

**光谱仪 (Spectrometer)** 用于测量光信号在不同波长上的功率分布 P(λ)， 是分析激光器线宽、EDFA 增益谱、WDM 信道间隔、滤波器通带等的核心仪器。

### 关键测量量

- **光谱功率密度**：P(λ)，单位 W/nm 或 dBm/nm
- **中心波长**：$\lambda_0 = \frac{\int \lambda P(\lambda)\, d\lambda}{\int P(\lambda)\, d\lambda}$
- **3 dB 谱宽**：功率下降到峰值一半对应的波长宽度
- **边模抑制比 (SMSR)**：主模与最大边模的功率比
- **波长精度**与**波长分辨率**

## 光栅光谱仪

**光栅光谱仪**基于衍射光栅分光，是经典且通用的光谱分析工具。

### 工作原理

1. 入射光经狭缝准直
2. 衍射光栅按波长在空间分离
4. 探测器阵列 (CCD/InGaAs) 同时采集整段光谱
3. （或旋转光栅，单探测器扫描采集）

### 衍射方程

光栅衍射满足光栅方程：

$$d \cdot (\sin\alpha + \sin\beta) = m \cdot \lambda$$

其中 d 为光栅周期，α/β 为入射/衍射角，m 为衍射级次。 不同波长对应不同衍射角，从而在空间分离。

### 特性

- **优点**：结构简单、成本低、波长范围宽、可便携
- **缺点**：分辨率受光栅刻线数与光路限制（0.1-10 nm），不适合窄线宽激光器精细测量

### 应用

- LED/LED 灯光谱测量
- 荧光光谱
- 颜色测量、反射率测量
- 教学与现场快速分析

## 光谱分析仪 (OSA)

**光谱分析仪 (OSA)** 是光通信领域专用的、高分辨率光谱测量仪器， 基于双通单色仪或傅里叶变换技术。

### 工作原理

OSA 内置可调谐滤波器（衍射光栅 + 狭缝）扫描波长，逐点测量功率：

1. 光信号进入 OSA
2. 双光栅单色仪扫描中心波长
3. 出射光由光电二极管检测功率
4. 软件绘制 P-λ 曲线

### 核心指标

| 指标 | 典型值 | 说明 |
| --- | --- | --- |
| 波长范围 | 600-1750 nm | 覆盖通信全波段 |
| 波长精度 | ±0.01-0.05 nm | 校准后 |
| 分辨率带宽 (RBW) | 0.01-10 nm 可调 | 决定谱线可分辨最小间隔 |
| 动态范围 | 40-70 dB | 主信号旁的微弱边模可测 |
| 功率精度 | ±0.3-0.5 dB | 经标准光源校准 |
| 功率线性度 | ±0.1-0.2 dB | 全量程一致性 |

### RBW 的影响

**分辨率带宽 (RBW)** 是 OSA 滤波器的通带宽度，决定可分辨的最小谱线间隔：

- RBW 太大：相邻谱线被"模糊"合并，线宽测得偏大
- RBW 太小：噪声大、扫描慢
- 经验法则：RBW ≤ 被测线宽的 1/3 才能准确测量线宽

### 动态范围

OSA 动态范围指主信号峰旁多少 dB 处仍能分辨微弱信号：

- **近端动态范围**：偏离主峰 ±1 nm 处的最低可测功率
- **远端动态范围**：偏离 ±10 nm 或更远处的最低可测功率

## 傅里叶变换光谱仪 (FTIR)

**傅里叶变换红外光谱仪 (FTIR)** 基于**迈克尔逊干涉仪**扫描光程差， 通过干涉图样傅里叶变换得到光谱，是宽谱、高分辨率测量的优选。

### 工作原理

1. 光信号进入迈克尔逊干涉仪
2. 动镜移动改变光程差 Δx
3. 探测器记录干涉信号 I(Δx)
4. 傅里叶变换得到光谱 B(ν)：

$$B(\nu) = \int I(\Delta x) \cdot e^{-i 2\pi \nu \Delta x}\, d(\Delta x)$$

### 优势（与光栅光谱仪对比）

- **多通道优势 (Fellgett)**：所有波长同时被探测，信噪比高，扫描快
- **光通量优势 (Jacquinot)**：无狭缝限制，光通量大，弱信号灵敏度高
- **波长精度高**：基于 HeNe 激光作为参考，波长精度达 ±10⁻⁴ nm

### 应用

- 气体成分分析（中红外指纹区）
- 材料红外透反射谱
- 高分辨率激光线宽测量
- 长波波段（L band、2 μm）光谱分析

## 波长计

**波长计 (Wavelength Meter)** 专注于**精确测量单色光源波长**， 精度远高于 OSA（可达 10⁻⁷ 量级），是相干通信激光器标定的必备仪器。

### 工作原理（迈克尔逊/菲佐干涉型）

- 基于迈克尔逊或菲佐 (Fizeau) 干涉仪
- 通过干涉条纹精确定位波长
- 内置 HeNe 参考激光溯源波长标尺
- 持续监测而非扫描，实时显示波长

### 关键指标

| 指标 | 数值 |
| --- | --- |
| 波长范围 | 400-1700 nm |
| 精度 | ±0.0001-0.001 nm |
| 测量速度 | 数 Hz-数 kHz |
| 适应多模激光 | 部分支持（菲佐型可分析） |

### 与 OSA 的区别

- **OSA**：宽范围、中精度、慢扫描、测谱形
- **波长计**：窄范围（单纵模）、超高精度、快测量、仅测中心波长

## 光谱仪的校准与误差

### 波长校准

- 用标准光源（如氪灯、氩灯特征谱线）校准波长刻度
- 用乙炔 (¹²C₂H₂) 或氢氰酸 (HCN) 吸收池做通信波段波长标准
- OSA 内置波长参考，但仍需定期校准

### 功率校准

- 用标准功率计（见第 02 章）溯源校准 OSA 功率轴
- RBW 切换时功率读数会变，需按 RBW 校准
- 跨波长测量时按探测器响应度修正

### 常见误差

- **波长漂移**：温度、机械振动
- **RBW 限制**：线宽被展宽
- **偏振相关响应 (PDL)**：不同偏振读数不同
- **多次反射**：连接器反射造成假谱线
- **动态范围不足**：弱边模被主信号掩盖

## 选型与典型应用

| 应用 | 推荐仪器 | 关键指标 |
| --- | --- | --- |
| LED/灯光光谱 | 小型光栅光谱仪 | 范围、便携、低成本 |
| 激光器线宽/SMSR | 高分辨率 OSA 或波长计 | RBW ≤0.01 nm，SMSR >50 dB |
| WDM 系统调试 | 通信 OSA | 信道间隔、动态范围 |
| EDFA 增益谱 | OSA + ASE 源 | 噪声底、平坦度 |
| 气体分析 | FTIR | 高分辨率、宽谱 |
| 激光器波长稳定 | 波长计 | 长期稳定、实时反馈 |

## 总结

光谱仪与波长计是表征光学信号频率域特性的核心仪器：

- **光栅光谱仪**：宽范围、低成本，适合一般光谱测量
- **OSA**：通信波段专用，分辨率高、动态范围大，是光通信首选
- **FTIR**：多通道优势、光通量大，适合宽谱高分辨率测量
- **波长计**：单色源波长超高精度测量，是激光器标定基准
- 选型核心：波长范围、分辨率 (RBW)、动态范围、精度、扫描速度
- 校准须定期溯源，注意 RBW 对线宽测量的影响
