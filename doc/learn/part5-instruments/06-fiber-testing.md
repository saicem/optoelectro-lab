# 光纤参数测量与故障定位

光纤的生产、施工与运维依赖一系列专用测量仪器，保证链路损耗、色散与连通性达标

## 光纤测量的核心参数

光纤链路的工程化指标决定了系统的传输质量：

| 参数 | 含义 | 仪器 |
| --- | --- | --- |
| 衰减系数 | dB/km，单位长度损耗 | OTDR / 截断法 |
| 总损耗 | 端到端 dB | 光源+功率计 / OTDR |
| 连接/熔接损耗 | 单点损耗 dB | OTDR |
| 色度色散 (CD) | ps/(nm·km) | CD 分析仪 |
| 偏振模色散 (PMD) | ps 或 ps² | PMD 分析仪 |
| 故障点位置 | 距离 m | OTDR |
| 端面质量 | 颗粒/划痕分级 | 端面检测仪 |

## 光时域反射计 (OTDR)

**OTDR (Optical Time-Dayin Reflectometer)** 是光纤施工与运维最核心的仪器， 利用瑞利散射与菲涅尔反射的回波信号，沿光纤距离轴绘制损耗分布。

### 工作原理

1. OTDR 发射短脉冲进入光纤
2. 沿途的瑞利散射产生连续回波，反映单位长度损耗
3. 故障点/端面产生菲涅尔反射尖峰，定位不连续点
4. 按时间-距离换算得到 P-L 曲线：

$$L = \frac{c \cdot t}{2 \cdot n_g}$$

其中 t 为回波时延，n_g 为群折射率，因子 2 来自往返双程。

### 关键指标

| 指标 | 含义 | 典型值 |
| --- | --- | --- |
| 动态范围 | 最大可测损耗 | 30-50 dB |
| 空间分辨率 | 区分两邻近点能力 | 0.5-5 m |
| 盲区 | 事件后无法分辨区域 | 1-20 m |
| 距离精度 | 长度测量误差 | ±1 m |
| 脉宽 | 影响分辨率与范围 | 5 ns - 20 μs |

### 脉宽与动态范围权衡

- 窄脉冲：分辨率高（可分熔接点），动态范围小
- 宽脉冲：动态范围大（可测长距），分辨率差
- 实测常分段扫描：先宽脉冲测全程，再窄脉冲细查故障段

### OTDR 曲线读图

- **斜坡**：光纤本征衰减
- **台阶式下落**：熔接/连接损耗
- **反射尖峰**：连接器端面、断裂点、光纤末端
- **台阶式上升**：连接器反射增益（罕见，折射率失配）

## 色散分析仪 (CD)

**色度色散 (CD) 分析仪**测量光纤的总色散与色散斜率，是高速率系统（>10G）开通前的必测项。

### 测量原理

- **相移法**：调制多个波长光，测量各波长经过光纤后的相位差，反推群时延 τ(λ)
- **脉冲时延法**：直接测量不同波长脉冲的到达时间差

色散系数由群时延对波长微分得到：

$$D(\lambda) = \frac{d\tau(\lambda)}{d\lambda} \quad (\text{ps/(nm·km)})$$

### 典型指标

- 波长范围：1260-1640 nm
- 色散范围：±300 ps/(nm·km)
- 精度：±0.05 ps/(nm·km)
- 动态范围：足够测 100+ km

## 偏振模色散分析仪 (PMD)

**PMD 分析仪**测量光纤两正交偏振主态的差分群时延 (DGD)， 是 40G/100G 系统开通前的关键测试项。

### 测量方法

- **干涉法 (INT)**：基于固定分析仪 (FA) 与干涉条纹分析，适合链路 PMD
- **琼斯矩阵特征分析法 (JME)**：扫描波长取各点琼斯矩阵，精度最高
- **波长扫描法 (WSFA)**：通过波长依赖的功率波动评估

### 典型指标

- PMD 范围：0.01-100 ps
- 精度：±0.02 ps
- 测试速度：秒级 (INT) 到分钟级 (JME)

### 链路 PMD 与平均 DGD

链路总 PMD 与长度关系（耦合长光纤）：

$$PMD_{link} = \sqrt{N} \cdot PMD_{fiber} \quad (\text{statistical model})$$

设计规则：PMD 引入的 DGD 须 < 10% 符号周期，否则需补偿或限速。

## 光纤端面检测仪

**光纤端面检测仪**用显微镜（200-400×）与相机检查连接器端面， 是插损与回波损耗不合格问题的第一道排查。

### 检查内容

- 划痕、裂纹、崩边
- 颗粒污染（灰尘、油污）
- 凹陷/凸起（PC/APC 研磨质量）
- 缺陷位置（核心区 vs 包层区）

### IEC 61314 端面分级

| 等级 | 含义 | 是否可用 |
| --- | --- | --- |
| Pass | 核心区无缺陷、无污染 | 可用 |
| Fail | 核心区有划痕/污染 | 必须清洁或研磨 |

便携式视频显微镜可实时观察，是机房与现场维护的标配。

## 光纤熔接机

**光纤熔接机**通过电弧放电熔接光纤，实现 <0.05 dB 的低损耗连接，是光纤工程的核心设备。

### 工作流程

1. 剥线、清洁、切割（端面平整度 <0.5°）
2. 放入熔接机 V 形槽，光纤自动对准（纤芯对芯，对芯式）
3. 电弧预热放电、推进熔接、强度测试
4. 热缩套管保护、盘纤

### 关键技术

- **纤芯对准 (Core Alignment)**：高精度机型用本地成像+微调，损耗 <0.02 dB
- **包层对准 (Cladding Alignment)**：经济型，损耗略大但够用
- **熔接损耗估算**：基于纤芯偏轴量推算，可信度 80%
- **拉力测试**：熔接后机械强度 >1.5 kg

### 特殊光纤

- 保偏光纤 (PMF) 熔接：须对快/慢轴，需偏振保持熔接机
- 多芯光纤 (MCF)：需三维对准、空分复用专用机型
- 弯曲不敏感光纤：放电参数需调整

## 光源+功率计组合（截断法）

作为 OTDR 的补充，**截断法 (Cutback)** 是实验室光纤损耗系数测量的基准方法：

1. 长光纤 L₁ 测得功率 P₁
2. 在距源 2 m 处剪断，测短光纤 L₂ 功率 P₂
3. 衰减系数：

$$\alpha = \frac{10 \log_{10}(P_2/P_1)}{L_1 - L_2} \quad (\text{dB/km})$$

精度极高（±0.01 dB/km），但破坏性测试，仅限出厂检测与科研。

## 综合测试方案

| 测试阶段 | 主要仪器 | 关注指标 |
| --- | --- | --- |
| 光纤出厂 | 截断法 + CD + PMD | 衰减系数、色散、PMD |
| 工程施工 | 熔接机 + 端面检测仪 | 熔接损耗、端面质量 |
| 链路开通 | OTDR + CD + PMD | 总损耗、断点、色散 |
| 运维监测 | OTDR + 端面检测 | 故障定位、清洁 |

## 总结

光纤测量仪器是光网络工程的基础工具：

- **OTDR**：损耗分布与故障定位的"听诊器"
- **CD/PMD 分析仪**：高速系统色散评估的必测项
- **端面检测仪**：连接器质量第一道排查
- **熔接机**：低损耗连接的工程化保障
- **截断法**：实验室损耗系数的基准方法
- 选型需匹配测试阶段：出厂、施工、开通、运维各有侧重
