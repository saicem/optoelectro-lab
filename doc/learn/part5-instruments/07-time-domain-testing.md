# 时域测试与误码分析

数字光通信的性能最终由时域波形与误码率验证，依赖一系列时域测试仪器

## 时域测试的核心目标

光通信系统的时域测试围绕"信号质量"展开，从波形到误码逐级评估：

| 层级 | 测试对象 | 关键仪器 | 关键指标 |
| --- | --- | --- | --- |
| 比特层 | 时域波形 | 光示波器 | 眼图、抖动、上升时间 |
| 误码层 | 比特正确率 | 误码仪 (BERT) | BER、误码秒 |
| 频域层 | 器件带宽 | 光波器件分析仪 (LCA) | S 参数、f_3dB |
| 相位层 | 激光线宽 | 相位噪声分析仪 | 线宽、相位噪声谱 |

## 光示波器

**光示波器 (Optical Sampling Oscilloscope)** 在电示波器基础上加光电转换前端， 直接观察光信号的时域波形，是数字调测最直观的工具。

### 类型

- **实时示波器**：连续采样，可捕获单次瞬态，带宽可达 70+ GHz
- **采样示波器**：重复信号触发式采样，等价带宽可达 100+ GHz，价格低但仅适于周期信号
- **光示波器**：内含光电前端（参考 Part 5 第 02 章光电二极管），直接接光纤

### 关键指标

| 指标 | 含义 | 通信典型要求 |
| --- | --- | --- |
| 带宽 | 模拟前端 f_3dB | >波特率 × 0.7 |
| 采样率 | 实时模式 Sa/s | >4×波特率 |
| 采样噪声底 | 等效噪声幅度 | <1 ps 抖动 |
| 光电转换 | 内置 PD 响应度 | A/W，需校准 |
| 触发抖动 | 时基稳定度 | <500 fs |

### 眼图测量

**眼图 (Eye Diagram)** 是评估数字信号质量最经典的方法：将比特流按周期叠加，形成"眼睛"形状的图形。

#### 眼图指标

- **眼高 (Eye Height)**：0/1 电平间隔，反映 SNR
- **眼宽 (Eye Width)**：交叉点间隔，反映定时裕量
- **抖动 (Jitter)**：边沿时间分布，含随机 (RJ) 与确定性 (DJ)
- **上升/下降时间**：t_r/t_f，限带宽
- **过冲/下冲**：阻抗失配引起
- **占空比失真 (DCD)**：高/低电平宽度不对称

#### 抖动分解

总抖动 (TJ) = 确定性抖动 (DJ) + 随机抖动 (RJ) × 14.1（BER=1e-12 对应 14σ）：

$$TJ_{pk-pk} = DJ + 2 \cdot 14.07 \cdot \sigma_{RJ}$$

RJ 为高斯分布，DJ 包含 DCD/ISI/正弦干扰等。

## 误码仪 (BERT)

**误码仪 (Bit Error Ratio Tester)** 产生 PRBS 码型、发送到被测系统， 在接收端逐位比对，统计错误比特数，是数字通信性能的"金标准"测试。

### 工作原理

1. 发送端产生 PRBS（伪随机码，如 PRBS-7/PRBS-31）
2. 信号经过被测链路（光纤、放大、调制、接收）
3. 接收端时钟恢复 + 比特判决
4. 与本地 PRBS 比对，统计错误比特

$$BER = \frac{N_{error}}{N_{total}}$$

### 测试码型

| 码型 | 长度 | 适用场景 |
| --- | --- | --- |
| PRBS-7 | 127 bit | 短码型，快速测 |
| PRBS-15 | 32767 bit | 中长码型 |
| PRBS-23 | 8M bit | 长码型，含低频分量 |
| PRBS-31 | 2G bit | 标准长码型，含 ISI |
| PRBS-13Q | - | 400G 灰码映射 |

### 关键指标

- **最大速率**：可达 100+ Gbps
- **码型**：PRBS 系列、用户自定义码型
- **误码检测灵敏度**：1e-15 量级（需长时间累计）
- **误码分布**：误码秒 (ES)、严重误码秒 (SES)、不可用秒 (UAS)

### BER 与 Q 因子的关系

实测 BER 可换算为 Q 因子（高斯近似）：

$$Q = \sqrt{2} \cdot \text{erfc}^{-1}(2 \cdot BER)$$

FEC 后 BER < 1e-15 视为无误码，FEC 前 BER < 1e-2 即可（见 Part 3 第 07 章 FEC）。

## 光波器件分析仪 (LCA)

**光波器件分析仪 (Lightwave Component Analyzer, LCA)** 用于测量电光/光电/光光器件的 **频率响应与 S 参数**，是器件带宽评估的核心仪器。

### 测量原理

- 内置扫频微波源（典型 0.1-67 GHz）
- 调制到光载波，经被测器件，光电转换回电信号
- 比对输入/输出得到 S21（频响）

### 关键测量

| 器件类型 | 测量参数 | 物理含义 |
| --- | --- | --- |
| 光电二极管 | 频响 f_3dB | 响应度随频率下降 |
| 电光调制器 | 调制带宽 | f_3dB 处电光转换效率 |
| 光放大器 | 增益带宽 | EDFA 平坦区 |
| TIA | 跨阻增益 | 输出 V/A |

### 关键指标

- 频率范围：0.1-67 GHz（67+ GHz 机型昂贵）
- 动态范围：60+ dB
- 群时延精度：±1 ps
- S 参数：S11/S21/S12/S22（含反射）

### 典型测试

- 光电二极管带宽测量 → 设计接收前端
- MZM 调制带宽测量 → 决定最高波特率
- EDFA 增益平坦度 → 决定 WDM 信道均衡

## 相位噪声与线宽测量

**相位噪声分析仪**评估激光器的频率稳定度，是相干通信激光器的核心指标。

### 测量原理

- **自零差法**：激光经迈克尔逊干涉，相位噪声转化为强度噪声
- **自外差法**：声光移频后再干涉，避免低频失真
- **光学频率鉴别器**：用边带解调直接得相位噪声

相位噪声谱密度 L(f) 单位为 dBc/Hz，由下式定义：

$$L(f) = 10 \log_{10}\left( \frac{S_\phi(f)}{2} \right) \quad (\text{dBc/Hz})$$

### 线宽提取

激光器线宽 Δν 由白相位噪声段推算：

$$\Delta \nu = \pi \cdot S_\phi^{white}(f) \quad (\text{Hz})$$

或用延迟自零差法测量（FWM 谱半高全宽 ÷ 2）。

### 典型指标

- 频率偏移范围：10 Hz - 100 MHz
- 灵敏度：-130 dBc/Hz
- DFB 线宽：100 kHz - 10 MHz
- ECL 线宽：<10 kHz
- 相干通信需求：<100 kHz

## 综合测试方案

| 系统类型 | 必测项 | 仪器组合 |
| --- | --- | --- |
| 直接调制 (DML) | 眼图 + BER | 光示波器 + BERT |
| 相干 100G+ | 调制器带宽 + 线宽 + BER | LCA + 相位噪声仪 + BERT |
| DWDM 系统 | 频谱 + BER + 误码分布 | OSA + BERT |
| 器件研发 | S 参数 + 频响 | LCA + 网络分析仪 |

## 总结

时域测试仪器是数字光通信性能评估的金标准：

- **光示波器**：眼图与抖动评估的直观工具
- **BERT**：比特正确率的最终判据
- **LCA**：电光/光电器件带宽评估的核心仪器
- **相位噪声仪**：激光线宽与频率稳定度的精密测量
- 时域测试与频域测试互补，共同验证系统设计
