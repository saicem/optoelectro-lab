# 无源光器件

光路中除光源与探测外，无源器件承担分束、合束、衰减、隔离、滤波等关键功能

## 无源器件的角色

**无源光器件 (Passive Optical Components)** 不需外部能量驱动，通过几何结构、介质膜、磁光效应等实现对光路的方向、强度、波长、偏振的被动控制。 是构建光路、测试系统、光网络的"积木"。

### 与有源器件的区别

| 维度 | 无源 | 有源 |
| --- | --- | --- |
| 能量供给 | 无 | 电/光泵浦 |
| 典型器件 | 衰减器、隔离器、环形器、分束器、滤波器、AWG | LD、PD、EDFA、调制器、光开关 |
| 增益 | 无放大 | 提供功率/相位/波长变化 |
| 工作机制 | 介质膜干涉、法拉第效应、波导耦合 | 受激辐射、电光效应 |

## 光衰减器 (VOA)

**光衰减器 (Variable Optical Attenuator, VOA)** 用于精确降低光功率， 在 BER 测试、接收灵敏度评估、EDFA 增益调节中不可或缺。

### 类型

| 类型 | 原理 | 特点 |
| --- | --- | --- |
| 步进 ND 滤波轮 | 不同密度滤光片切换 | 粗调，固定衰减档 |
| 手动 VOA | 旋转偏振片对 | 简单可靠，分辨率有限 |
| 电调 VOA (MEMS) | MEMS 微镜改变耦合角 | 响应 ms，自动化 |
| 电调 VOA (热光/电光) | 波导相位/耦合改变 | 集成化，功耗低 |
| 高功率 VOA | 风冷/水冷吸收体 | 数十 W 不损 |

### 关键指标

- 衰减范围：0-60 dB（典型）
- 衰减精度：±0.1 dB
- 衰减分辨率：0.01 dB（电调）
- 插损（最小衰减态）：0.5-1.5 dB
- 波长相关损耗 (WDL)：跨波段衰减一致性
- PDL：偏振相关损耗，<0.1 dB
- 响应时间：ms（MEMS）/ μs（电光）

### 应用场景

- **接收机灵敏度测试**：扫描 BER vs 接收功率
- **EDFA 增益评估**：控制输入功率范围
- **OTDR 动态范围扩展**：避免强信号饱和
- **OSNR 测试**：本振光功率匹配

## 光隔离器

**光隔离器 (Optical Isolator)** 只允许光单向通过，抑制反射回光源， 是保护 DFB/ECL 激光器、稳定线宽与功率的关键器件。

### 工作原理

基于 **法拉第旋光效应**（磁光效应，磁场使偏振面非互易旋转 45°）：

1. 入射光经起偏器成为线偏振
2. 经法拉第旋光器，偏振面旋转 45°
3. 检偏器透光轴对齐 45°，光通过
4. 反射光反向经旋光器，再旋 45°（非互易），共 90° 偏振
5. 起偏器阻止反射光，实现单向隔离

### 类型

- **偏振相关隔离器 (PDI)**：基于偏振，隔离度高（>50 dB）但需保偏光纤
- **偏振无关隔离器 (PI)**：用双折射晶体分离偏振再合并，适合普通单模光纤
- **多级隔离器**：两片级联，隔离度 >60 dB

### 关键指标

- 隔离度：典型 40-60 dB
- 插损：0.3-0.8 dB
- PDL：偏振无关型 <0.1 dB
- 工作波段：通信单波段或宽波段
- 回波损耗：>50 dB
- 耐功率：低功率型 300 mW，高功率型数 W

### 使用注意

- 反射回光源会破坏激光器谐振腔稳定，**必须**加装隔离器
- 相干通信激光器须多级隔离，保护窄线宽特性
- 高功率 EDFA 输入/输出都装隔离器，避免 ASE 反馈

## 光环形器

**光环形器 (Optical Circulator)** 是隔离器的"多端口版"： 光按固定方向在端口间路由（1→2→3→...），反向被阻挡， 是反射式传感、OADM、双向系统的核心器件。

### 工作原理

同样基于法拉第旋光效应，但配合偏振分束器与反射镜实现多端口循环：

- 1→2：直通
- 2→3：反射回的光被路由到 3 端口，不返回 1
- 3→1：反向传输被阻止

### 类型

- 3 端口环形器：最常见
- 4 端口环形器：用于 WDM 解复用
- 偏振无关型：通信主流
- 多级集成：多波长路由

### 关键指标

| 指标 | 典型值 |
| --- | --- |
| 方向性（隔离度） | >50 dB |
| 端口间插损 | 0.6-1.5 dB |
| 串扰（反向） | < -50 dB |
| 回波损耗 | >50 dB |
| PDL | <0.1 dB |

### 应用

- **FBG 反射式传感**：FBG 反射光经环形器路由到接收机，避免反射回激光器
- **OADM 上/下路**：波长上/下分插复用
- **双向传输系统**：用单纤双向传输，环形器分离收发
- **色散补偿反射式**：DCF 模块以反射式节省长度

## 光分束器与合束器

**光分束/合束器 (Coupler/Splitter)** 实现功率分配或合并， 是构建干涉仪、采光、广播通信的基础器件。

### 类型

- **Y 分支**：波导型，集成化
- **X 型对称耦合器**：熔融拉锥 (FBT) 主流工艺
- **PLC 平面波导分路器**：1×N (N=2-128)，集成度高
- **偏振分束器 (PBS)**：按偏振分路，配合偏振器件
- **波分复用器 (WDM coupler)**：按波长分路

### 关键指标

- 分光比：1×N（如 1×8 均分 = 各 12.5%）
- 分光精度：±1 dB
- 附加损耗：0.05-0.5 dB
- 方向性：>55 dB（隔离反向传输）
- 工作带宽：单波段或宽波段
- PDL：<0.1 dB

### 应用

- **光纤到户 (FTTH)**：1×32 分路器，广播到用户
- **干涉仪参考臂**：MZ 干涉仪采分参考光
- **接收端采样**：1% 采光做在线监测
- **PBS/PBC**：偏振复用系统的偏振合/分路

## 滤波器

**滤波器 (Filter)** 按波长选择透射或反射，是 WDM、传感、调谐的核心。 详细器件原理在 Part 4 第 02 章已介绍，本章补充选型与测试视角。

### 类型对比

| 类型 | 机制 | 带宽 | 应用 |
| --- | --- | --- | --- |
| 薄膜滤波器 (TFF) | 介质膜干涉 | 50-200 GHz | CWDM、DWDM 单信道 |
| 阵列波导光栅 (AWG) | 平面波导衍射 | 25-100 GHz | DWDM 解复用 |
| 光纤布拉格光栅 (FBG) | 周期折射率调制 | 0.1-1 nm | 滤波、传感 |
| 法布里-珀罗 (FP) | 谐振腔滤波 | GHz 可调 | 调谐、传感 |
| 可调滤波器 (TOF) | 衍射光栅+声光 | nm 可调 | OSA 内部分光 |

### 关键指标

- 中心波长与精度
- 通带带宽（FWHM）
- 通带平坦度
- 阻带隔离度（>40 dB）
- 插损
- 通带色散（窄带滤波器关注）
- 偏振相关损耗 (PDL)
- 温度系数（热稳定性）

## 无源器件的通用指标

所有无源器件共享的工程指标，是测试与选型时须综合权衡的：

| 指标 | 含义 | 重要性 |
| --- | --- | --- |
| 插入损耗 (IL) | 器件引入的功率损失 | 关键，越小越好 |
| 回波损耗 (RL) | 反射回输入端的光 | >50 dB 防止反射串扰 |
| 偏振相关损耗 (PDL) | 偏振态引入的损耗差 | <0.1 dB 通信要求 |
| 波长相关损耗 (WDL) | 波段内损耗一致性 | 影响 WDM 系统平坦度 |
| 温度稳定性 | 损耗随温度漂移 | 户外环境关键 |
| 工作波段 | 支持波长范围 | 匹配系统波段 |
| 方向性/串扰 | 反向/邻端泄漏 | 影响系统隔离 |
| 耐功率 | 不损坏的最大功率 | 高功率场景必查 |
| PMD | 器件引入的差分群时延 | 高速系统必查 |

## 综合测试方案

| 器件 | 主要仪器 | 测试项 |
| --- | --- | --- |
| VOA | 光源+功率计 | 衰减精度、WDL、PDL |
| 隔离器 | 光源+功率计+反向端口 | 隔离度、插损、回损 |
| 环形器 | 同上+多端口测量 | 方向性、串扰、端口损耗 |
| 分路器 | 光源+功率计+多端口 | 分光精度、附加损耗 |
| 滤波器 | TLS+OSA | 通带、隔离度、PMD、色散 |

## 总结

无源器件是构建光路的"积木"，承担方向、强度、波长、偏振控制：

- **衰减器 (VOA)**：精确控制功率，灵敏度测试必备
- **隔离器**：保护光源，抑制反射，相干激光器刚需
- **环形器**：多端口非互易路由，反射式传感核心
- **分束器/合束器**：功率分配与广播，PLC 集成主流
- **滤波器**：波长选择，WDM/传感/调谐核心
- 通用指标（IL/RL/PDL/WDL/PMD/温度稳定性）是选型与测试的关键
